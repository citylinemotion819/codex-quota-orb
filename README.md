## ⚙️ Usage Tips

You can move the widget by clicking and dragging the main orb frame. To change settings, right-click the orb to open the menu.

**Settings Menu**
Right-clicking the widget allows you to adjust the transparency and size of the orb. You can also hide specific data points if you prefer a simpler look.

**Update Notifications**
The app checks for new versions when you open it. If a new version exists, a small arrow appears on the orb. Click this arrow to visit the release page and update your tool.

**Local Data Security**
This tool stores all usage data on your local hard drive. No personal credentials leave your computer.

## 💡 Troubleshooting

If you encounter issues during installation or while running the widget, try these steps:

**Widget does not appear**
Check your system tray near the clock. Sometimes the widget minimizes there instead of opening on the desktop. Right-click the icon in the tray and select "Show Widget."

**Data is missing**
Verify that your internet connection is stable. The widget needs a connection to pull your latest quota and credit information. You can force a refresh by clicking the "Refresh Data" option in the right-click menu.

**Slow performance**
Close other applications that use high amounts of memory. If the widget still runs slow, check for pending Windows updates.

**Installation errors**
If the installer fails, turn off your antivirus program for a few minutes. Sometimes security software blocks new apps from running script installers. Remember to turn your antivirus back on after the installation finishes.
